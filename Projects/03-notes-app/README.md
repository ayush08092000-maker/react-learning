# Notes App 📝

A modern and responsive Notes App built using React and Tailwind CSS.

## 🚀 Features

* Add and delete notes
* Responsive layout
* Dynamic note rendering using map()
* Real-time UI updates
* Input validation
* Sticky note style design
* Clean and modern interface

## 🛠️ Tech Stack

* React JS
* Tailwind CSS
* JavaScript (ES6)

## 📂 Folder Structure

 ├── App.jsx
 ├── main.jsx

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-github-repo-link>
```

Go to project folder:

```bash
cd notes-app
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
