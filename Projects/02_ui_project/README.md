# Customer Segmentation UI

A modern and responsive customer segmentation UI built using React and Tailwind CSS.

## 🚀 Features

* Responsive layout
* Reusable React components
* Dynamic card rendering using props and map()
* Modern UI design
* Horizontal scroll cards
* Hover animations
* Tailwind CSS styling

## 🛠️ Tech Stack

* React JS
* Tailwind CSS
* Lucide React Icons

## 📂 Folder Structure

```bash
src/
 ├── components/
 ├── assets/
 ├── data/
```

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-github-repo-link>
```

Go to project folder:

```bash
cd 02_ui_project
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
